# Lamport proof skills

Turn a mathematical proof into a numbered hierarchy of claims and justifications, then explore it in a standalone HTML page.

- [`lamport-proof-json`](lamport-proof-json/SKILL.md) encodes a proof from prose, LaTeX, or an outline. Its validator checks the JSON structure and explicit dependencies.
- [`lamport-proof-site`](lamport-proof-site/SKILL.md) builds an expandable proof explorer with TeX math, linked steps, and optional passage-specific Codex chats.

## Install in Codex

Clone the repository and copy both folders into your Codex user skills directory. Keep them side by side so the explorer can find the JSON validator.

```sh
git clone https://github.com/ReplicaWormhole/my-skill.git
cd my-skill
mkdir -p ~/.agents/skills
cp -R lamport-proof-json lamport-proof-site ~/.agents/skills/
```

For a project-only installation, copy the two folders into that project's `.agents/skills/` directory. Start a new Codex session and invoke `$lamport-proof-json` to encode a proof or `$lamport-proof-site` to build the explorer.

## Try the example

The validator uses Python 3 and its standard library. The explorer builder also needs Pandoc with sandbox and MathML support on your `PATH`. From the repository root, run:

```sh
python3 -B lamport-proof-json/scripts/validate.py lamport-proof-json/references/example.json
python3 -B lamport-proof-site/scripts/build.py lamport-proof-json/references/example.json --output proof-site/index.html
```

Open `proof-site/index.html` in a modern browser. The page includes the proof text, styles, and scripts and can be read offline. Review the proof text and source metadata before sharing a generated page. JSON validation checks the document structure and dependencies. Mathematical validity requires a separate proof review.

## Optional local chat

Chat requires a signed-in Codex CLI on your `PATH`. Serve HTML generated by the builder:

```sh
python3 -B lamport-proof-site/scripts/serve.py proof-site/index.html
```

Open the loopback address printed by the server and select a passage. Sending a question submits relevant proof excerpts, selected text, and recent conversation history through your Codex CLI. The browser stores discussion history and highlights for the local site and proof revision. Run the chat server on your own machine and keep it on loopback.
